## 1. 徐行と一時停止

  - A: false
  - Exp: 横断する人がいないことが明らかな場合は、そのままの速度で進行することができます。

  - A: true
  - Exp: 停止線の直前（ない場合は交差点の直前）で一時停止し、左右の安全を確認した後は進行できます。
- Q3: 見通しのきかない交差点（信号機なし、優先道路ではない）を通行するときは、必ず一時停止しなければならない。
  - A: false
  - Exp: 必ず「一時停止」ではなく、「徐行」しなければなりません。
- Q4: 児童や幼児が乗り降りするためにストップマークを出して止まっている通学通園バスのそばを通るときは、後方で一時停止して安全を確かめなければならない。
  - A: true
  - Exp: 子供の飛び出しに備え、必ず後方で一時停止して安全を確認する必要があります。
- Q5: 歩行者のそばを通るときは、歩行者との間に安全な間隔をあけるか、徐行しなければならない。
  - A: true
  - Exp: 安全な間隔がとれない場合は、必ず徐行しなければなりません。
- Q6: ぬかるみや水たまりのある所を通行するときは、泥や水をはねて他人に迷惑をかけないように徐行しなければならない。

  - Exp: 歩行者などに泥水をはねないよう、徐行する義務があります。
- Q7: 道路の曲がり角付近は、見通しが良くても徐行しなければならない。
  - A: true
  - Exp: 道路の曲がり角付近は、見通しの良し悪しに関わらず徐行場所です。
- Q8: 上り坂の頂上付近と、勾配の急な上り坂は、どちらも徐行しなければならない。
  - A: false
  - Exp: 徐行場所は「上り坂の頂上付近」と「勾配の急な下り坂」です。急な上り坂は徐行場所ではありません。
- Q9: 横断歩道のない交差点で、歩行者が横断しているときは、警音器を鳴らして注意を促し、徐行して通行する。
  - A: false
  - Exp: 警音器を鳴らすのではなく、一時停止して歩行者の通行を妨げないようにしなければなりません。
- Q10: 安全地帯のそばを通るときは、歩行者がいなくても必ず徐行しなければならない。
  - A: false
  - Exp: 安全地帯に歩行者がいる場合は徐行が必要ですが、いない場合は徐行の義務はありません。
- Q11: 警察署長が許可した歩行者用道路を自動車で通行するときは、特に歩行者がいない場合、徐行しなくてもよい。
  - A: false
  - Exp: 歩行者用道路を通行する際は、歩行者の有無に関わらず常に徐行しなければなりません。
- Q12: 交差点を左折するときは、あらかじめできるだけ道路の左端に寄り、交差点の側端に沿って徐行しなければならない。
  - A: true
  - Exp: 左折時の基本的なルールであり、巻き込み事故を防ぐために重要です。
- Q13: 前方の信号が赤色の点滅をしているとき、自動車は他の交通に注意して徐行して進行することができる。
  - A: false
  - Exp: 赤色の点滅信号は「一時停止」しなければなりません。徐行で通過できるのは黄色の点滅です。
- Q14: 踏切を通過するときは、踏切の直前で一時停止し、窓を開けるなどして自分の目と耳で安全を確認しなければならない。
  - A: true
  - Exp: 信号機付きの踏切で青信号に従う場合を除き、必ず一時停止と安全確認が必要です。
- Q15: 路線バスが発進の合図を出したので、後方で一時停止してバスを先に発進させた。
  - A: false
  - Exp: 発進を妨げてはいけませんが、「一時停止」ではなく「徐行」して道を譲るのが基本です。
- Q16: 身体障害者用の車いすが通行しているそばを通るときは、一時停止するか徐行しなければならない。

- Q17: 交差点で右折しようとするときは、あらかじめできるだけ道路の中央に寄り、交差点の中心のすぐ内側を徐行しなければならない。
  - A: true
  - Exp: 右折の基本ルールです（一方通行路から右折する場合を除く）。
- Q18: 優先道路を通行しているときは、交差点で見通しがきかなくても徐行する必要はない。
  - A: true
  - Exp: 優先道路を通行している場合は、左右の見通しがきかない交差点でも徐行の義務は免除されます。
- Q19: 前の車が交差点で左折するため合図を出したときは、その後方を徐行してついていかなければならない。
  - A: false
  - Exp: そのままついていくのではなく、前の車が左折を完了するまで減速や一時停止で待つなど、安全を図ります。
- Q20: 「徐行」とは、車がすぐに停止できる速度で進行することをいい、具体的には時速10キロメートル以下のことである。
  - A: false
  - Exp: 徐行とは「車がすぐに停止できるような速度（一般的には時速10km以下）」ですが、法律上明確な数字（時速何km）の定義はありません。

## 2. 追い越しと追い抜き
- Q1: トンネル内では、車両通行帯（車線）がある場合を除き、他の自動車を追い越してはならない。
  - A: true
  - Exp: トンネル内は原則追い越し禁止ですが、車両通行帯が設けられている場合に限り追い越し可能です。
- Q2: 交差点とその手前30メートル以内の場所では、他の自動車や原動機付自転車を追い越したり、追い抜いたりしてはならない。
  - A: false
  - Exp: 追い越しは禁止されていますが、「追い抜き（進路を変えずに側方を通過）」は禁止されていません。
- Q3: 前の車が右折するため道路の中央に寄って通行しているときは、その左側を追い越さなければならない。
  - A: true
  - Exp: 前の車が右折のために中央に寄っている場合は、例外としてその左側を追い越します。
- Q4: 勾配の急な上り坂と、勾配の急な下り坂は、どちらも追い越しが禁止されている。
  - A: false
  - Exp: 「勾配の急な下り坂」と「上り坂の頂上付近」は追い越し禁止ですが、「急な上り坂」自体は禁止場所ではありません。
- Q5: 路線バスが停留所から発進するため右の方向指示器を出したが、急ブレーキをかければ間に合う距離だったので、そのまま追い越した。
  - A: false
  - Exp: 急ブレーキで避けなければならない場合を除き、乗合自動車の発進を妨げてはいけません。
- Q6: 追い越しをするときは、前の車が右折の合図を出していない限り、必ずその右側を通行しなければならない。
  - A: true
  - Exp: 追い越しは原則として右側から行うと定められています。
- Q7: 前の車が原動機付自転車を追い越そうとしているとき、さらにその後ろから前の車を追い越した（二重追い越し）。
  - A: false
  - Exp: 前の車が自動車ではなく「原動機付自転車や軽車両」を追い越している場合の二重追い越しは禁止されていません。禁止されるのは、前の車が「自動車」を追い越そうとしている場合です。
- Q8: 踏切とその手前30メートル以内の場所は、追い越しが禁止されている。
  - A: true
  - Exp: 踏切とその手前30mは、追い越し禁止場所です。
- Q9: 横断歩道とその手前30メートル以内の場所では、前の車を追い越してはならないが、追い抜くことはできる。
  - A: false
  - Exp: 横断歩道等とその手前30m以内は、追い越しも「追い抜き」も両方禁止されています。
- Q10: 追い越し禁止の標識がある場所でも、原動機付自転車であれば追い越してもよい。
  - A: false
  - Exp: 「追い越し禁止」の標識がある場合、自動車だけでなく原動機付自転車を追い越すことも禁止されています（軽車両は可）。
- Q11: 道路の曲がり角付近は、見通しが良くても追い越しが禁止されている。
  - A: true
  - Exp: 道路の曲がり角付近は、見通しの良し悪しに関わらず追い越し禁止場所です。
- Q12: 追い越されるときは、追い越しが終わるまで速度を上げてはならないが、左に寄る義務はない。
  - A: false
  - Exp: 速度を上げてはいけないだけでなく、十分な余地がない場合はできるだけ左に寄り、進路を譲る義務があります。
- Q13: 前の車が自動車を追い越そうとしているときに、自分もその車を追い越すことは「二重追い越し」となり禁止されている。
  - A: true
  - Exp: 前の車が「自動車」を追い越そうとしている場合の二重追い越しは、極めて危険なため禁止されています。
- Q14: 「追越しのための右側部分はみ出し通行禁止」の標識がある場所でも、原動機付自転車を追い越すためであれば、右側部分にはみ出してもよい。
  - A: false
  - Exp: この標識がある場合、対象が何であれ、道路の右側部分にはみ出して追い越しをすることはできません。
- Q15: 追い越しが終わって左側の車両通行帯に戻るときは、ルームミラーやドアミラーで追い越した車が確認できたら、すぐに進路変更をしてよい。
  - A: false
  - Exp: すぐに戻るのではなく、ルームミラーで追い越した車が十分後ろに見えるくらいの安全な距離をとってから戻ります。
- Q16: 優先道路を通行しているときは、交差点とその手前30メートル以内でも、他の自動車を追い越すことができる。
  - A: true
  - Exp: 交差点付近での追い越しは原則禁止ですが、自分が優先道路を通行している場合は例外として追い越し可能です。
- Q17: 追い越しをするときは、対向車や後続車だけでなく、前の車の進行状況にも注意を払わなければならない。
  - A: true
  - Exp: 前の車が急に右折したり進路変更したりする可能性があるため、十分な注意が必要です。
- Q18: 道路の左端に寄って停車している車を避けて通るのは、「追い越し」ではなく「障害物を避ける措置」である。
  - A: true
  - Exp: 停止している車などの横を通り過ぎることは、追い越しには該当しません。
- Q19: オートマチック車で追い越しをする際、加速力を得るためにアクセルペダルを一気に踏み込むことをキックダウンという。
  - A: true
  - Exp: キックダウンにより一時的に低いギアに切り替わり、強い加速力を得ることができます。
- Q20: 夜間、他の車を追い越すときは、前照灯をこまめに上向きや下向きに切り替えたり、警音器を鳴らしたりして合図を送るのがよい。
  - A: false
  - Exp: むやみに前照灯を切り替えたり警音器を鳴らしたりするのは、相手の目を眩ませたり迷惑になったりするため不適切です（合図自体は前照灯の切り替えで行うことはあります）。

## 3. 駐車禁止と駐停車禁止
- Q1: 駐車場や車庫などの自動車専用の出入り口から3メートル以内の場所は、駐車も停車もしてはならない。
  - A: false
  - Exp: 出入り口から3m以内は「駐車禁止」ですが、「停車」は禁止されていません。
- Q2: 交差点とその端から5メートル以内の場所は、駐停車禁止場所である。
  - A: true
  - Exp: 交差点とその端から5m以内は、駐車も停車も禁止されています。
- Q3: 踏切とその端から10メートル以内の場所は、駐車は禁止されているが、人の乗り降りのための停車は可能である。
  - A: false
  - Exp: 踏切とその端から10m以内は「駐停車禁止」場所であり、停車もできません。
- Q4: 火災報知機から1メートル以内の場所は、駐車禁止場所である。
  - A: true
  - Exp: 消防用防火水槽などの周辺（5m以内）や、火災報知機から1m以内は駐車禁止です。
- Q5: 坂道では、上り坂の頂上付近と勾配の急な下り坂は駐停車禁止であるが、勾配の急な上り坂は駐停車禁止ではない。
  - A: false
  - Exp: 坂の頂上付近、急な下り坂、そして「勾配の急な上り坂」のいずれも駐停車禁止場所です。
- Q6: 路線バスの停留所の標示柱から10メートル以内の場所は、バスの運行時間外であれば駐車してもよい。
  - A: true
  - Exp: 停留所から10m以内は駐停車禁止ですが、それは「運行時間中」に限られます。運行時間外は駐停車禁止場所から外れます。
- Q7: 道路工事の区域の端から5メートル以内の場所は、駐車禁止場所である。
  - A: true
  - Exp: 工事区域の端から5m以内は、駐車が禁止されています（停車は可）。
- Q8: 軌道敷内（路面電車の線路部分）は、駐車は禁止されているが、停車は禁止されていない。
  - A: false
  - Exp: 軌道敷内は、原則として駐車も停車も禁止されています（駐停車禁止場所）。
- Q9: 車の右側に3.5メートル以上の余地がない場所では、原則として駐車してはならない（無余地駐車の禁止）。
  - A: true
  - Exp: 他の交通の妨げになるため、右側に3.5m以上の余地がなくなる場所での駐車は禁止されています。
- Q10: 荷物の積み下ろしのための停止で、5分を超えるものは「駐車」になる。
  - A: true
  - Exp: 荷物の積み下ろしによる停止は、5分以内なら「停車」、5分を超えると「駐車」になります。
- Q11: 人の乗り降りのための停止は、時間に関係なく「停車」である。
  - A: true
  - Exp: 人の乗り降りのための停止は、客待ちなどを除き、何分かかっても「停車」として扱われます。
- Q12: 横断歩道とその手前30メートル以内の場所は、駐停車禁止場所である。
  - A: false
  - Exp: 横断歩道とその「前後5メートル以内」が駐停車禁止場所です。30メートル以内は追い越し・追い抜き禁止場所です。
- Q13: 自動車を駐車するときは、道路の左端に沿って停めなければならない。
  - A: true
  - Exp: 駐車・停車するときは、原則として道路の左端に沿って停める必要があります。
- Q14: 「駐車余地」の標識により、車の右側に6メートルの余地をあけるよう指定されている場所では、余地が5メートルしかなくても短時間なら駐車してよい。
  - A: false
  - Exp: 標識で余地が指定されている場合は、その距離（この場合は6m）を確実にあけなければ駐車できません。
- Q15: パーキング・メーターが設置されている時間制限駐車区間では、指定された枠内に正しく停めれば、制限時間を超えても駐車してよい。
  - A: false
  - Exp: 時間制限駐車区間では、指定された時間を超えて駐車し続けることはできません。
- Q16: 消火栓や指定消防水利の標識がある位置から5メートル以内の場所は、駐車禁止である。
  - A: true
  - Exp: 消防活動の妨げになるため、消火栓等から5m以内は駐車禁止です。
- Q17: 故障などのやむを得ない理由で駐停車禁止場所に車を停める場合でも、標示器材を置くなどの危険防止措置をとれば駐車してよい。
  - A: false
  - Exp: 故障であっても駐停車禁止場所での駐車はできません。速やかに安全な場所まで移動させる義務があります。
- Q18: 運転者が車から離れており、すぐに運転できない状態であれば、停止時間が1分でも「駐車」になる。
  - A: true
  - Exp: 運転者が離れて直ちに運転できない状態（放置駐車）は、時間の長短に関わらず「駐車」となります。
- Q19: 歩道上であっても、歩行者の通行の妨げにならなければ、二輪自動車を駐車してよい。
  - A: false
  - Exp: 歩道上は、原則として自動車や二輪車の駐車は禁止されています。
- Q20: 駐車場などの自動車専用の出入口から3メートル以内の場所では、自分の車庫の前であれば駐車してもよい。
  - A: false
  - Exp: たとえ自分の車庫の前であっても、出入り口から3m以内は駐車禁止です（自分が入れなくなる等の理由は関係なく法律で禁止）。

## 4. 車検と定期点検
- Q1: 自家用乗用自動車の初めての車検（継続検査）は、新車で購入してから3年後に行う。
  - A: true
  - Exp: 自家用乗用車の初回車検は3年目、それ以降は2年ごとに行います。
- Q2: 自動車の日常点検は、長距離ドライブの前や洗車時など、月に1回程度行えばよい。
  - A: false
  - Exp: 日常点検は、走行距離や運行時の状態から判断して適切な時期に行います（月に1回という決まりはありません）。
- Q3: 車検切れの自動車でも、自賠責保険（強制保険）の期限が切れていなければ、公道を運転してもよい。
  - A: false
  - Exp: 車検が切れた車は、公道を運転してはいけません。無車検車運行となります。
- Q4: 検査標章（車検のステッカー）は、フロントガラスの内側の見やすい位置に貼り付けなければならない。
  - A: true
  - Exp: 検査標章は、前面ガラスの内側の前方から見やすい位置（令和5年より原則として運転席側上部等）に貼り付けます。
- Q5: 定期点検整備は、専門の知識が必要なため、必ず整備工場などの専門業者に依頼しなければならない。
  - A: false
  - Exp: 定期点検整備は、ユーザー自身で行うことも認められています（ユーザー車検・ユーザー点検）。
- Q6: 自動車検査証（車検証）は、原本を自宅で大切に保管し、運転時はコピーを携帯すればよい。
  - A: false
  - Exp: 自動車検査証は、必ず「原本」を車に備え付けておかなければなりません。電子車検証の場合はその原本と自動車検査証記録事項を備え付けます。
- Q7: 自動車損害賠償責任保険（自賠責保険）証明書は、運転する際、必ず自動車に備え付けておかなければならない。
  - A: true
  - Exp: 車検証と同様に、自賠責保険証明書も必ず車に備え付ける義務があります。
- Q8: 原動機付自転車（原付）や総排気量250cc以下の二輪車には、車検（自動車検査）の制度がない。
  - A: true
  - Exp: 原付や250cc以下の二輪自動車（軽二輪）には、車検制度はありませんが、自賠責保険の加入と日常点検は必要です。
- Q9: バッテリーの液量が上限と下限の間にあれば、正常である。
  - A: true
  - Exp: バッテリー液は、上限（UPPER LEVEL）と下限（LOWER LEVEL）の間にあれば正常です。
- Q10: タイヤの溝の深さは、スリップサインが一部でも現れていたら、そのタイヤは使用してはならない。
  - A: true
  - Exp: スリップサイン（残り溝1.6mmの目印）が1箇所でも出ているタイヤは、使用禁止です。
- Q11: ブレーキペダルの遊びは、全くない方がブレーキが早く効くため安全である。
  - A: false
  - Exp: ブレーキペダルには、適度な「遊び」が必要です。遊びがないとブレーキが引きずった状態になる恐れがあります。
- Q12: ファンベルトを指で押したとき、全くたわまない状態が適正な張り具合である。
  - A: false
  - Exp: ファンベルトは、中央部を指で押した時に適度な「たわみ」がある状態が正常です。
- Q13: エンジンオイルの量は、オイルレベルゲージのF（上限）とL（下限）の間にあれば正常である。
  - A: true
  - Exp: オイルレベルゲージの上限と下限の間にオイルの跡がつけば適正量です。
- Q14: 自賠責保険（強制保険）は、対人賠償だけでなく、他人の車や物を壊したときの対物賠償も補償される。
  - A: false
  - Exp: 自賠責保険は「対人賠償（被害者のケガや死亡）」のみを補償するもので、対物賠償は含まれません。
- Q15: 車を改造して車体の大きさや排気量が変わった場合は、15日以内に記載事項の変更手続きをしなければならない。
  - A: true
  - Exp: 構造や定員、最大積載量などが変わった場合は、15日以内に変更の手続きが必要です。
- Q16: 大型自動二輪車および普通自動二輪車（250ccを超えるもの）の初回車検は、新車購入から2年後である。
  - A: false
  - Exp: 250ccを超える自動二輪車の新車登録時の初回車検は「3年」です（以降は2年ごと）。
- Q17: 保安基準に適合しないように改造された車（不正改造車）は、運転してはならない。
  - A: true
  - Exp: 違法なマフラーや着色フィルムなど、保安基準に適合しない不正改造車の運転は禁止されています。
- Q18: ウィンドウウォッシャー液が不足しているときは、代わりに水道水を入れても全く問題ない。
  - A: false
  - Exp: 寒冷時に凍結したり、洗浄力が落ちたり、ノズルが詰まる原因になるため、専用のウォッシャー液を使うべきです。
- Q19: 排気の色が無色、または淡い青色であれば、エンジンは正常な状態である。
  - A: true
  - Exp: 排気ガスが無色または淡青色であれば正常です。黒色や白色の場合はエンジントラブルの可能性があります。
- Q20: 任意保険（自動車保険）は加入が自由であるため、自賠責保険に入っていれば加入しなくても交通事故の賠償は十分にカバーできる。
  - A: false
  - Exp: 自賠責保険には支払限度額があり、対物補償もないため、自賠責保険だけでは十分な賠償ができない場合が多く、任意保険の加入が強く推奨されます。

## 5. 最高速度と最大積載量
- Q1: 標識や標示で最高速度が指定されていない一般道路では、普通乗用車の最高速度は時速60キロメートルである。
  - A: true
  - Exp: 法定速度は、一般道路において自動車（普通乗用車など）は時速60kmです。
- Q2: 総排気量125cc以下の小型二輪自動車は、高速自動車国道を通行することができる。
  - A: false
  - Exp: 高速自動車国道を通行できる二輪車は、総排気量125ccを超える自動二輪車です。
- Q3: 普通自動車の最大積載量は、車両の大きさに応じて運転者が自由に決めることができる。
  - A: false
  - Exp: 最大積載量は、自動車検査証（車検証）に記載されている重量を超えてはいけません。
- Q4: 標識で最高速度が時速50キロメートルに指定されている道路でも、原動機付自転車の最高速度は時速30キロメートルである。
  - A: true
  - Exp: 原付の法定最高速度は時速30kmであり、標識でそれ以上が指定されていても時速30kmを超えて走ることはできません。
- Q5: 荷物を積むとき、荷台から後方に車体の長さの10分の1まではみ出して積むことができる。
  - A: false
  - Exp: 荷物の長さの制限は「自動車の長さの1.2倍」までであり、はみ出してよいのは車体の前後から自動車の長さの10分の1（1割）までです（令和4年法改正）。
- Q6: 普通乗用車で他の車をロープで牽引するときの法定最高速度は、時速40キロメートルである。
  - A: false
  - Exp: 総重量2,000kg以下の車をその3倍以上の重量の車で牽引する場合は時速40kmですが、それ以外の一般的なロープ牽引は時速30kmが法定最高速度です。
- Q7: 自動車の積載物の高さの制限は、地上から3.8メートル（軽自動車は2.5メートル）までである。
  - A: true
  - Exp: 地上からの高さ制限は、普通車等で3.8m、軽自動車や三輪自動車で2.5mまでです。
- Q8: 自動車の積載物の幅の制限は、自動車の幅の1.2倍までである。
  - A: true
  - Exp: 令和4年の法改正により、積載物の幅の制限は「自動車の幅の1.2倍」までとなりました（左右のはみ出しは自動車の幅の10分の1ずつまで）。
- Q9: 大型貨物自動車の一般道路での法定最高速度は、時速50キロメートルである。
  - A: false
  - Exp: 大型貨物自動車であっても、一般道路での法定最高速度は普通車と同じ時速60kmです。
- Q10: 荷物を積むとき、方向指示器やナンバープレート、尾灯などが見えなくなるような積み方をしてはならない。
  - A: true
  - Exp: 合図や標識が見えなくなる積み方は、安全運転の妨げとなるため禁止されています。
- Q11: 出発地を管轄する警察署長の許可を受ければ、制限を超える大きさや重さの荷物を積んで運転することができる。
  - A: true
  - Exp: 分割できない荷物などを運ぶ際、警察署長の許可（制限外積載許可）を得れば、条件付きで運搬可能です。
- Q12: 制限外積載許可を受けた場合、荷物の見やすい箇所に、昼間は赤い布（0.3m四方以上）、夜間は赤い反射器か赤い灯火をつけなければならない。
  - A: true
  - Exp: はみ出した荷物の危険を知らせるため、これらの目印を付ける義務があります。
- Q13: 原動機付自転車の最大積載量は、30キログラムである。
  - A: true
  - Exp: 原付の最大積載量は30kg、積載装置からのはみ出しは後方へ0.3mまで、左右へは0.15mまでです。
- Q14: 原動機付自転車に荷物を積む場合、高さは地上から2.0メートルまで許される。
  - A: true
  - Exp: 原付の積載物の高さ制限は、地上から2.0mまでです。
- Q15: 自動二輪車の最大積載量は、排気量に関係なく一律60キログラムである。
  - A: true
  - Exp: 自動二輪車（大型・普通）の最大積載量は、荷台や乗車装置に乗せる場合、一律60kgです。
- Q16: 高速自動車国道の本線車道における、大型乗用自動車（バス）の法定最高速度は時速100キロメートルである。
  - A: true
  - Exp: 大型乗用車（バス）の高速道路での最高速度は、普通乗用車と同じ時速100kmです（大型貨物とは異なります）。
- Q17: 高速自動車国道の本線車道における、大型貨物自動車の法定最高速度は時速90キロメートルである。
  - A: true
  - Exp: 令和6年4月の法改正により、大型トラック（大型貨物自動車等）の高速道路における法定最高速度は時速80kmから90kmに引き上げられました。
- Q18: 雨天や濃霧で視界が悪いときでも、法定最高速度で走らなければ交通の妨げになる。
  - A: false
  - Exp: 法定最高速度は「出してもよい最高の速度」であり、悪天候など状況が悪い時は、安全な速度まで減速する義務があります。
- Q19: 総排気量50cc以下の原動機付自転車は、標識で最高速度が時速50キロメートルに指定されている一般道路では、その速度で走ってよい。
  - A: false
  - Exp: 標識での指定速度に関わらず、原動機付自転車の法定最高速度である時速30kmを超えてはいけません。
- Q20: 故障車を牽引するとき、牽引される車にはその車を運転できる免許を持つ者を乗せ、ハンドルやブレーキの操作をさせなければならない。
  - A: true
  - Exp: ロープ等で牽引する場合は、牽引される車に免許を持つ人が乗り、操作を行う必要があります。
